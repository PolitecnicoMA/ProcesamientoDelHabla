# Procesamiento del Habla - Repositorio de Proyectos
### Tecnicatura Superior en Ciencia de Datos e IA

Este repositorio compila los proyectos y experimentos realizados en la materia **Procesamiento del Habla**. El objetivo principal es dotar a los estudiantes de herramientas para el análisis, síntesis y reconocimiento de la voz humana y señales sonoras.

## Descripción del Contenido
Los desarrollos aquí presentes cubren las siguientes dimensiones técnicas:
* **Análisis de Señales Acústicas:** Representación de señales en tiempo y frecuencia (Espectrogramas).
* **Procesamiento de Lenguaje Natural (NLP):** Técnicas de preprocesamiento de texto para la interacción verbal.
* **Reconocimiento de Voz (ASR):** Implementación de sistemas para la transcripción automática de audio a texto.
* **Síntesis de Habla (TTS):** Generación de voz artificial a partir de datos textuales.

## Tecnologías y Herramientas
* **Lenguajes:** Python.
* **Librerías Especializadas:** Librosa, PyAudio, NLTK, Spacy, Wave.
* **Modelos:** Integración con APIs de reconocimiento y modelos preentrenados.

## Perfil Técnico Desarrollado
En alineación con los objetivos de segundo año, este repositorio demuestra:
1. Capacidad para procesar datos no estructurados de tipo audio.
2. Desarrollo de interfaces de interacción humano-computadora mediante la voz.
3. Aplicación de modelos de Aprendizaje Automático en dominios acústicos.
